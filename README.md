# AI Assistant Prototype

An early multi-AI assistant interface prototype exploring the idea of bringing multiple AI systems into a single unified workspace.

This project was originally built with v0 as an early product and interface concept. It later evolved into **Philomath**, a full-stack multi-AI application with authentication, persistent conversations, secure API key management, file uploads, and real AI provider integrations.

---

## Overview

Using multiple AI platforms often means switching between different websites, interfaces, and conversation histories.

The AI Assistant Prototype explored a different approach:

**What if multiple AI assistants could be accessed from one interface?**

The project focused primarily on interface design, interaction modes, and the overall product concept before a full backend system was implemented.

---

---

## Interaction Modes

### Basic Mode

A simple conversational experience designed for quick questions and general AI interaction.

### Manual Mode

Designed to give users control over which AI assistant or model handles a request.

### Auto Mode

An early concept for automatically selecting or coordinating AI systems depending on the user's request.

These ideas later influenced the development of Philomath.

## Philomath

The current evolution of this project is **Philomath**.

Philomath expands the original concept into a full-stack multi-AI workspace where users can connect their own AI providers and interact with them through one unified interface.

Philomath includes:

* Google authentication
* Bring Your Own API Key architecture
* Multiple AI providers
* Encrypted API key storage
* Persistent conversations
* Per-user integrations
* Multi-file uploads
* FastAPI backend
* Supabase authentication and database
* Cloud deployment
